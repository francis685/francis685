### 📈 Daily Git Commit & VLSI Workflow

For a VLSI designer, daily commits are just as important as they are for a software developer. Here is my professional strategy:

1.  **Version Control your RTL & Testbenches:** Treat your Verilog/VHDL like software. Commit incremental changes to your logic, finite state machines, and verification environments daily.
2.  **RTL Simulation & Waveforms:** Don't just save a waveform. Commit a Markdown file analyzing your simulation results (e.g., VCD file analysis or timing violations).
3.  **Physical Design Iterations:** Document your floorplanning, synthesis logs, and place-and-route constraints. Even committing small changes to a synthesis script keeps your activity green.
4.  **Hardware & IoT Integration:** Commit changes to your Arduino/C++ code, IoT sensor configurations, or even KiCad schematic updates. *Everything* counts.
